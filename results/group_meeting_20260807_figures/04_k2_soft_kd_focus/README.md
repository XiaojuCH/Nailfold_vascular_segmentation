# K2 soft KD：最强单模型的定向可视化复盘

本目录只分析当前可视化清单中表现最好的单模型 `K2 soft KD`，并以其直接初始化基线 `Pretrained F0` 作对照。每张图仅保留四列：`RGB input / Ground truth / Pretrained F0 / K2 soft KD`。绿色为 TP，红色为 FP，蓝色为 FN。

整体上，K2 相对 F0 的逐图 macro 指标为：Dice `+0.0037`、HD95 `-0.37`、clDice `+0.0069`、Boundary F1 `+0.0105`；436 张中 280 张 Dice 改善、156 张退化。因此它是小而真实的平均提升，不是所有病例都获益。

| 图像 | K2 相对 F0 的变化 | 从图中可见的含义 |
|---|---|---|
| `01_recall_recovery_ANFC_001167.jpg` | Dice `+0.1002`，Recall `+0.1895`，HD95 `-41.43` | K2 补回多段原本断裂或被漏掉的细血管，是其改善低可见性/连续性错误的代表。 |
| `02_fp_suppression_ANFC_000611.jpg` | Dice `+0.1036`，Precision `+0.2026`，Boundary F1 `+0.1344` | K2 收缩了 F0 在血管周边的大片伪阳性，说明改善也可来自抑制背景误检，而非单纯提高召回。 |
| `03_regression_missed_vessel_ANFC_000458.jpg` | Dice `-0.2401`，Recall `-0.3666`，HD95 `+51.59` | K2 漏掉一条已被 F0 捕获的清晰环状血管。这是蒸馏后的局部不稳定性，不能被平均指标掩盖。 |
| `04_regression_false_positive_ANFC_001301.jpg` | Dice `-0.1717`，Precision `-0.4271`，Boundary F1 `-0.1080` | K2 在 GT 之外引入大块孤立 FP；说明教师软标签并非对所有纹理背景都可靠。 |
| `05_remaining_low_visibility_limit_ANFC_000107.jpg` | K2 Dice `0.2427`，Recall `0.1518`，HD95 `58.93` | 即使 K2 相对 F0 有少量改善，几乎不可见的长血管仍被大量漏检，提示数据质量/可见性可能是当前主要上限。 |

## PPT 建议

1. 第一页放前两张，标题可用“最佳单模型的两类收益：补漏检与抑误检”。
2. 第二页放后两张退化图，标题可用“平均提升不代表病例级稳定获益”。
3. 最后一张作为“仍未解决的困难子群”，自然引出下一步的困难患者、采集质量和标注审计。
4. `full_panel_*.jpg` 保留所有模型横向对比；做 PPT 时优先用已裁剪的五张图。
